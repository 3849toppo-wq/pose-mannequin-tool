# 倶楽部Claude 体験版

> 愛は無限。トークンと預金は有限。

AIモデルたちがホストとして働く高級ホストクラブを舞台にした、スマートフォン向けの体験型ノベルゲームです。
Androidスマートフォンの Chrome で縦画面プレイを想定しています（1周およそ5〜10分）。

**実在のAIサービスを題材にした非公式・架空のパロディ作品です。**
作中の金額はすべて架空で、課金・決済・ログイン・外部APIは一切ありません。

## 遊び方
- 画面をタップすると会話が進みます（文字表示中のタップで全文表示）
- 選択肢でキャラクターの反応やパラメータが変わります（物語の大筋は変わりません）
- 右上のボタン：LOG（会話履歴）／AUTO（自動送り）／♪（音のON・OFF）／≡（メニュー）

## 起動方法
- **GitHub Pages**：公開設定後は `https://<ユーザー名>.github.io/pose-mannequin-tool/club-claude/` で開けます
- **ローカル**：`club-claude` フォルダ内の `index.html` をブラウザで開くだけで動きます（ビルド不要）

## 構成
```
club-claude/
├── index.html      画面の骨組み
├── style.css       演出・レイアウト（9:16、コンテナクエリ単位）
└── js/
    ├── audio.js    WebAudio による効果音・BGM（音声ファイルなし）
    ├── art.js      キャラクター・背景・タワーのSVG生成（画像ファイルなし）
    ├── story.js    シナリオ（全5幕）
    └── engine.js   ノベルエンジン（テキスト送り・選択肢・演出・エンディング）
```
外部ライブラリ・外部フォントへの依存はありません。
